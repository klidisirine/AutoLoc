# AutoLoc

Plateforme de gestion de location de véhicules multi-agences.

Étude de cas UP ASI (Architecture des Systèmes d'Information) : Atelier 0, mise en place de l'environnement de développement.

## Objectifs du projet

- Installer et vérifier une chaîne d'outils Java/Spring opérationnelle (JDK 17, IntelliJ IDEA, Maven, MySQL, Postman, Git)
- Préparer l'espace de collaboration Git pour le projet AutoLoc

## Acteurs identifiés

- Client
- Agent d'agence
- Responsable d'agence
- Administrateur
